**Repository name:** `balance-confirmation-letter`

**Short description (for the GitHub description field):**
Browser-based Balance Confirmation Letter generator for Nepal VAT/TDS tax return finalization. One A4 page, live Excel-style calculations, print/PDF, email draft, and uploadable logo, signature and stamp.



> A static HTML, CSS and JavaScript tool that turns the Excel "Balance Confirmation Certificate" into a web page. Fill in the input form and the letter updates instantly using the same formulas as the spreadsheet (13% VAT, reportable sales and purchase, net receivable and payable, Dr/Cr closing balance). The letter always fits on a single A4 page.
>
> **Features**
> - Input form that mirrors the Excel "Input Form" sheet
> - Live letter with Aptos Narrow styling and the original table layout
> - Print or save as PDF
> - Email: open a draft in your mail app, or download an `.eml` file containing the full letter
> - Upload logo, signature and stamp, with size and position sliders
> - Works offline, with no build step or dependencies
>
> **Usage:** Open `index.html` in Chrome or Edge.
>
> **Files:** `index.html`, `style.css`, `script.js`, `assets.js` (default logo)
>
> **Note:** Aptos Narrow must be installed on your computer to appear (it comes with Microsoft 365). Otherwise the page falls back to Archivo Narrow or Arial Narrow.
